# संत ज्ञानेश्वर महाराज / Sant Dnyaneshwar Maharaj

A reading and research portal on Sant Dnyaneshwar Maharaj, part of the "Maharashtra Sants" library.
It is a plain static site (HTML, CSS, JavaScript and JSON data), served by GitHub Pages from the `main` branch.

The portal is being prepared. Data shown in it is marked with its evidence status; rows marked provisional
await replacement by the library's own research.
